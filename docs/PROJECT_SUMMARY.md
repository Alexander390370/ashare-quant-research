## 三、做出来的东西

### A 线：筛选层（screening/，584 行）

**功能**：从指数成分股生成可复现的候选池

| 项 | 实现 |
|---|---|
| 数据源 | 中证指数官网 + 腾讯日线 + 交易所名称 |
| 硬规则 | 排除 ST / 上市≥12个月 / 日均成交额≥5000万 / 排除停牌 |
| 输出 | candidates.csv + rejected.csv（含剔除原因）+ audit.json |
| 可复现 | 配置快照 + 零随机 + 同日跑两次结果一致 |

**数据源压力测试（每源 8 次）**：

| 源 | 成功率 | 结论 |
|---|---|---|
| 中证 沪深300 | 8/8 = 100% | ✅ 稳定 |
| 中证 中证500 | 8/8 = 100% | ✅ 稳定 |
| 腾讯 日线 | 8/8 = 100% | ✅ 稳定 |
| 新浪 日线 | 8/8 = 100% | ✅ 稳定 |
| 全A代码名称 | 7/8 = 88% | ⚠️ 需重试 |
| **东财 日线** | **0/8 = 0%** | ❌ **已弃用** |

**实测结果**：800 只 → **793 只通过（剔除率 0.9%）**

**这个 0.9% 是重要发现**：指数成分股已被中证筛过，硬规则几乎不起作用。

### B 线：因子排序（qlib_layer/，2889 行）

| 项 | 实现 |

### ① 修复权（已完成）

**问题**：腾讯日线默认不复权，除权日跳空污染动量因子。

**修复**：改用前复权 `qfq`，配置接通（之前是死配置）。

**实测证据**：

| 股票 | 不复权首价 | 前复权首价 | 差异 |
|---|---|---|---|
| 贵州茅台 | 1684.58 | 1531.13 | -9.1% |
| 工商银行 | 4.73 | 3.65 | -22.8% |
| **比亚迪** | 238.54 | 76.80 | **-67.8%** |

**一个重要反驳**：六家曾一致说应该用 hfq（后复权），**但实测 qfq 才对**：

| 口径 | 跨除权日 20 日动量（工行） |
|---|---|
| 不复权 | +14.18% |
| **前复权 qfq** | **+17.70%** ← 消除假跌，最接近真实 |
| 后复权 hfq | +8.51% ← 反而更低 |

---

### ② 自动防线（已完成）

**问题**：因子写反靠人工才发现，下次静默出错。

**修复**：三道防线，12 项校验

| 防线 | 内容 |
|---|---|
| **防线 1** | 方向断言跑**真实 Qlib 表达式引擎**（构造合成行情 → 灌 Qlib → D.features 算） |
| **防线 2** | 三条不变量：权重取反→排名互补、截断未来→历史不变、重跑两次→一致 |
| **防线 3** | 独立复算：`.bin` 原始字节 vs Qlib 读取值 |

**关键突破：变异测试 6/6 全部捕获**

```
mom20 方向写反          ✅ 捕获（3 项变红）
mom5 方向写反           ✅ 捕获
rev1 符号写反           ✅ 捕获
vol20 窗口错位 20→10    ✅ 捕获
dev20 符号写反          ✅ 捕获
vol_ratio 分子分母颠倒   ✅ 捕获
```

**顺带发现一个真 bug**：Qlib 的 `Std()` 用 **ddof=1**（样本标准差），不是 ddof=0。这导致参照实现系统性偏离 2.6%。

## 四、回测结论：两个策略都无效

### 策略 1：动量 + 低波（原方案）❌

| 指标 | 数值 |
|---|---|
| 累计收益 | +38.99% |
| 基准（全池等权） | +71.58% |
| **超额** | **-32.59%** |
| IC 均值 | -0.0273 |
| 最大回撤 | -33.03% |
| 换手 | 192.3% |
| **入选 vs 影子** | **+38.99% vs +73.28%（跑输 34 个点）** |

**结论：跑输基准，甚至跑输被排除的股票。**

### 策略 2：纯反向（看到 IC 为负后反转）❌

**样本内（2023-2026，34 期）看起来很好：**

| 指标 | 数值 |
|---|---|
| 累计收益 | +171.37% |
| 超额 | +99.79% |
| 最大回撤 | -15.41% |

**但三项稳健性检验只有 1/3 通过：**

| 检验 | 结果 |
|---|---|
| A 分时段 | 2/3 为正，但第 2 段 **-8.15%**，第 3 段贡献绝大部分 |
| B 市场状态 | 上涨市 +2.98% / 下跌市 **-0.35%** → 只在牛市有效 |
| C 参数敏感性 | Top20 月度 +99.79% / **Top20 周度 -7.77%（回撤 -49.08%）** |

**样本外（2018-2023，68 期）彻底失败：**

| 指标 | 样本外 | 样本内 |
|---|---|---|
| **IC 均值** | **-0.0060** | +0.0280 |
| **IC t 统计量** | **-0.25** | +0.78 |
| 组合累计 | +378.10% | +137.37% |
| 官方指数 | **-8.77%** | +38.66% |
| 随机 20 只 | +134.39% | +68.71% |
| 最大回撤 | -47.24% | -19.62% |

**关键**：样本外 IC = **-0.0060**，方向反了且接近 0。

## 五、三个致命缺陷（不可修复）

### ① 幸存者偏差

**问题**：793 只是 **2026 年当前**的成分股，用它回测 2018 年，被剔除的历史衰退/退市股不在池中。

**证据**：样本外「随机 20 只」都能 +134.39% —— 这批股票是活到 2026 年的赢家，自带巨大偏差。

**为什么修不了**：

> 中证公告只给成分进出名单，**不重建退市股、历史 ST、长期停牌、重组换名的交易状态**。
> 腾讯接口只给现存个股，**退市股根本没有数据源**。
>
> —— DeepSeek

### ② IC 统计不显著，且数学上不可检验

**实测**：样本内 t=0.78，样本外 t=-0.25，都远低于 1.96。

**更致命的数学论证**（MiniMax）：

```
周频 t ≈ IC × √N
要 t = 1.96：
  N=68  需要 IC = 0.24
  N=150 需要 IC = 0.16

而真实截面因子 IC 普遍 0.02 - 0.05
```

**这意味着：即使信号真实存在，现有数据也永远无法证明。**

### ③ A 线剔除率仅 0.9%

**原因**：中证成分股已被按市值+流动性筛过，4 条硬规则在干净池子上无事可做。

**这不是 bug，是逻辑必然** —— 但也说明「筛选层」这个定位是错的。

## 八、对抗式评审的最终裁决

**正方（GPT-6 Luna / Kimi / Qwen）vs 反方（DeepSeek / Doubao / MiniMax）**
**裁判：GPT-6 Luna**

**反方赢，但不是全胜。**

| 争点 | 判决 |
|---|---|
| 策略层还有 alpha 吗 | **反方胜**（OOS IC=-0.006，两个独立时段都无法拒绝零假设） |
| 三样资产有价值吗 | **正方胜**（变异测试、qfq/hfq 实测、推翻六家判断，都是真一手证据） |
| 该不该修 PIT 池 | **反方略胜**（IC=0.24 才显著，真实因子只有 0.02-0.05） |
| 该不该继续做量化 | **反方胜**（非专业交易员 + 免费数据 + 无 GPU，结构性错配） |

**裁判的明确建议：转向**

> "暂停因子策略实盘与参数搜索，保留工程成果；
> **只做一次有明确准入条件的 PIT 数据审计**。
> 数据无法审计，就封存该策略线。"

**裁判的一句话**：

> **"这项目值得留下当研究工具，但目前不值得拿真金白银替它的回测背书。"**

## 十二、最后

**这套系统现在的真实定位：**

```
你的财富管理范式（你有，但未落地）
        ↓
交易方案（你有，但未验证）
        ↓
【可交易池生成器】← A 线，能用
        ↓
【深度分析】← TradingAgents，能用
        ↓
执行（没有）
```

**中间那层「选股 alpha」是空的，而且我们证明了在当前条件下填不上。**

**但这不代表整条链路没用** —— 一个能稳定产出候选池、能做深度分析、能诚实告诉你「这个策略不行」的系统，**比一个声称能预测涨跌的黑箱有用得多**。
