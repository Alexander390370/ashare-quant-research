## 五、三个不可修复的缺陷

### ① 幸存者偏差

**问题**：793 只是 **2026 年当前**的成分股，用它回测 2018 年，退市股不在池中。

**证据**：样本外「随机 20 只」都能 +134.39% —— 这批股票是活到 2026 年的赢家。

**为什么修不了**：中证公告只给成分进出名单，**退市股没有数据源**。

### ② IC 统计上不可检验

**数学论证：**

```
周频 t ≈ IC × √N
要 t = 1.96：
  N=34  需要 IC = 0.336
  N=68  需要 IC = 0.238
  N=75  需要 IC = 0.226
  N=150 需要 IC = 0.160

真实截面因子 IC 普遍 0.02 - 0.05
```

**即使信号真实存在，现有数据也永远无法证明。**

### ③ 前视偏差难以彻底消除

**财务数据只有报告期，没有公告日。** 只能用法定披露截止日近似：

```
一季报 (03-31) → 04-30 可得
半年报 (06-30) → 08-31 可得
三季报 (09-30) → 10-31 可得
年报   (12-31) → 次年 04-30 可得
```

**这是保守估计，但仍有误差**（实际公告可能早于截止日）。

## 六、踩过的坑（可复用经验）

### 数据层

| 坑 | 现象 | 修法 |
|---|---|---|
| **东财全线不可用** | `stock_zh_a_hist` 0/8 失败 | 改用腾讯/新浪（都 100%） |
| **并发比串行更稳** | 串行成功率 55%，并发 100% | `ThreadPoolExecutor(workers=10)`，快 6 倍 |
| **Qlib `.bin` 格式** | 第一个 float32 是起始索引 | 加 `np.hstack([[0], arr])` |
| **Windows multiprocessing** | Qlib 用 joblib，spawn 报错 | 必须放 `if __name__ == "__main__"` |
| **千分位逗号** | 股本 `"19,405,918,198"` → NaN | 先 `.str.replace(",", "")` |
| **财务数据升序** | `iloc[0]` 是最老的 2023Q1 | 必须 `iloc[-1]` |
| **行业分类混用** | 证监会门类 + 申万行业并存 | 统一到申万一级 |

### 因子层

| 坑 | 现象 | 修法 |
|---|---|---|
| **Qlib `Ref` 语义** | `Ref($close,N)` 是 N 天前 | 动量必须 `$close/Ref(...)` |
| **Qlib `Std` 用 ddof=1** | 参照实现偏离 2.6% | 必须 `np.std(..., ddof=1)` |
| **复权口径** | 六家都说 hfq 对 | **实测 qfq 才对**（跨除权日 20 日动量：qfq +17.70% / hfq +8.51%） |
| **配置未接线** | 改 config 系统纹丝不动 | 必须真的把参数传下去 |
| **上市时长误判** | 拉 3 年数据时「最早日期」=窗口起点 | 用 `list_date` 字段 |

### 回测层

| 坑 | 现象 | 修法 |
|---|---|---|
| **NaN 传播** | 全部结果 nan | 过滤 NaN + 剔除基准缺失的期 |
| **基准选错** | 全池等权自带小盘 alpha | 必须加「随机 N 只 bootstrap」对照 |
| **性能** | 57 万行面板反复布尔过滤 | 预索引 + bisect，快 10 倍 |
| **事后反向** | 看到 IC 为负才反转 | 这是样本内拟合，必须做样本外 |
| **PIT 查询慢** | 500 只 × 75 期 pandas 过滤 | 预建索引 + 二分查找 |
