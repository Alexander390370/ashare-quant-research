## 三样能用的东西

### 1. A 线：筛选层

**能力**：从指数成分股生成可复现的候选池

| 项 | 实现 |
|---|---|
| 数据源 | 中证指数官网 + 腾讯日线 + 交易所名称 |
| 硬规则 | 排除 ST / 上市≥12个月 / 日均成交额≥5000万 / 排除停牌 |
| 输出 | `candidates.csv` + `rejected.csv`（含剔除原因）+ `audit.json` |
| 可复现 | 配置快照 + 零随机 + 同日跑两次结果一致 |

**数据源压力测试（每源 8 次）**：

| 源 | 成功率 |
|---|---|
| 中证 沪深300 | **8/8 = 100%** |
| 中证 中证500 | **8/8 = 100%** |
| 腾讯 日线 | **8/8 = 100%** |
| 新浪 日线 | **8/8 = 100%** |
| 全A代码名称 | 7/8 = 88% |
| **东财 日线** | **0/8 = 0%**（已弃用） |

```bash
python -m screening.run              # 全量（800 只，约 4 分钟）
python -m screening.run --limit 10   # 快速验证
```

### 2. B 线：自动防线

**能力**：让因子错误自己报警，而不是靠人工核对

**三道防线，12 项校验**：

| 防线 | 内容 |
|---|---|
| **防线 1** | 方向断言跑**真实 Qlib 表达式引擎**（构造合成行情 → 灌 Qlib → `D.features` 算） |
| **防线 2** | 三条不变量：权重取反→排名互补、截断未来→历史不变、重跑两次→一致 |
| **防线 3** | 独立复算：`.bin` 原始字节 vs Qlib 读取值 |

**核心设计：因子定义唯一真源**

`qlib_layer/factors.py` 是因子表达式的唯一来源，`run.py` 和 `validate.py` 都从这里导入。
改这里 = 同时改生产代码和被校验对象，无法再各自漂移。

**变异测试 6/6 全部捕获**：

```
mom20 方向写反          ✅ 捕获（3 项变红）
mom5 方向写反           ✅ 捕获
rev1 符号写反           ✅ 捕获
vol20 窗口错位 20→10    ✅ 捕获
dev20 符号写反          ✅ 捕获
vol_ratio 分子分母颠倒   ✅ 捕获
```

```bash

python tools/mutation_test.py              # 完整变异套件（6 种）
```

## 三个不可修复的缺陷

### ① 幸存者偏差

**问题**：793 只是 **2026 年当前**的成分股，用它回测 2018 年，被剔除的历史衰退/退市股不在池中。

**证据**：样本外「随机 20 只」都能 +134.39% —— 这批股票是活到 2026 年的赢家。

**为什么修不了**：

> 中证公告只给成分进出名单，**不重建退市股、历史 ST、长期停牌、重组换名的交易状态**。
> 腾讯接口只给现存个股，**退市股根本没有数据源**。

### ② IC 统计不显著，且数学上不可检验

**实测**：样本内 t=0.78，样本外 t=-0.25，都远低于 1.96。

**更致命的数学论证**：

```
周频 t ≈ IC × √N
要 t = 1.96：
  N=68  需要 IC = 0.24
  N=150 需要 IC = 0.16

而真实截面因子 IC 普遍 0.02 - 0.05
```

**这意味着：即使信号真实存在，现有数据也永远无法证明。**

### ③ A 线剔除率仅 0.9%

**原因**：中证成分股已被按市值+流动性筛过，4 条硬规则在干净池子上无事可做。

**这不是 bug，是逻辑必然** —— 但也说明「筛选层」这个定位是错的。

## 踩过的坑（可复用的经验）

### 数据层

| 坑 | 现象 | 修法 |
|---|---|---|
| **东财全线不可用** | `stock_zh_a_hist` 0/8 失败 | 改用腾讯/新浪（都 100%） |
| **并发比串行更稳** | 串行成功率 55%，并发 100% | `ThreadPoolExecutor(workers=10)`，快 6 倍 |
| **Qlib `.bin` 格式** | 第一个 float32 是起始索引 | 加 `np.hstack([[0], arr])` |
| **Windows multiprocessing** | Qlib 用 joblib，spawn 报错 | 必须放 `if __name__ == "__main__"` |

### 因子层

| 坑 | 现象 | 修法 |
|---|---|---|
| **Qlib `Ref` 语义** | `Ref($close,N)` 是 N 天前 | 动量必须 `$close/Ref(...)`，不是反过来 |
| **Qlib `Std` 用 ddof=1** | 参照实现偏离 2.6% | 必须用 `np.std(..., ddof=1)` |
| **复权口径** | 六家都说 hfq 对 | 实测 qfq 才对（跨除权日 20 日动量：qfq +17.70% / hfq +8.51%） |
| **配置未接线** | 改 config 系统纹丝不动 | 必须真的把参数传下去 |

### 回测层

| 坑 | 现象 | 修法 |
|---|---|---|
| **NaN 传播** | 全部结果 nan | 过滤 NaN + 剔除基准缺失的期 |
| **基准选错** | 全池等权自带小盘 alpha | 必须加「随机 20 只 bootstrap」对照 |
| **性能** | 57 万行面板反复布尔过滤 | 预索引 `{code: (dates, closes)}` + bisect，快 10 倍 |
| **事后反向** | 看到 IC 为负才反转 | 这是样本内拟合，必须做样本外 |
