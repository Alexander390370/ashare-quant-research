在看结论之前，先说明这套东西是怎么跑出来的。**不然后面那些数字会显得没头没尾。**

### 一句话版本

> 用 **AKShare** 拉全市场数据，用 **Qlib** 算因子和回测，然后用三道关卡挨个卡一遍。
> **九条策略进去，零条活着出来。**

### 怎么验证的：三道门 + 一个关不掉的漏洞

这是整个项目的核心方法。**每一条策略都要依次过这三道门，任何一道过不了就出局。**
另外还有一个漏洞——它是所有个人量化的通病，**关不掉，只能带着它走路**。

```
第①道门：前视偏差（Look-ahead）
  └─ 问题：用 2026 年的财报去选 2023 年的股票？（这叫偷看未来）
  └─ 做法：PIT（Point-in-Time）——每个调仓日只用「当时已公布」的财报
  └─ 判据：样本外 IC 必须 > 0 且方向一致

第②道门：风格暴露（Style Exposure）
  └─ 问题：赚的钱是「选股准」，还是「小盘股刚好涨得好」？
  └─ 做法：市值中性化——在市值分档内选股，消除小盘效应
  └─ 判据：中性化后 IC 仍显著

第③道门：统计显著性（t-test）
  └─ 问题：这个 IC 会不会只是噪声？
  └─ 做法：算 t 统计量，门槛 1.96（95% 置信）
  └─ 判据：|t| > 1.96


关不掉的漏洞：幸存者偏差（Survivorship）
  └─ 问题：股票池只有「活到今天」的 5223 只，退市股不在里面
  └─ 后果：所有回测收益被系统性高估
  └─ 为什么不修：退市股没有免费数据源——中证公告只给成分进出名单，
                 不重建退市/ST/长期停牌的日线。腾讯、新浪都只给现存个股。
  └─ 处理：诚实记录 + 用「随机选股」做对照基准，看策略能不能跑赢随机
```

**最后这条漏洞是理解整个仓库的钥匙：** 因为它在，所以任何「看起来很赚」的回测数字都要打折看。这也是为什么本项目最终的结论是「全部无效」而不是「找到了一个能赚 99% 的策略」。

## 核心结论（先看这个）

### 九个策略，全部无效

**价量因子：**

| 策略 | 结果 |
|---|---|
| 动量 + 低波 | 超额 **-32.59%**，跑输被排除股票 34 个点 |
| 纯反向 | 样本内 +99.79%，**样本外 IC=-0.0060（t=-0.25）** |
| 按 IC 重配 | 超额 +29.45%，稳健性未通过 |

**财务因子（非 PIT，前视 2.8 年）—— 看起来 4/5 显著：**

| 策略 | vs 随机 | IC | t 值 |
|---|---|---|---|
| quality_growth | +80.99% | +0.0435 | **+2.92** |
| quality | +48.93% | +0.0316 | **+2.26** |
| quality_value | +11.71% | +0.0361 | **+2.17** |
| growth | +91.35% | +0.0341 | **+2.14** |
| value | +4.78% | +0.0116 | +0.60 |

**PIT 修正后（无前视）—— 全部失效：**

| 策略 | 期数 | vs 随机 | IC | t 值 |
|---|---|---|---|---|
| quality | 75 | **-32.96%** | **-0.0123** | **-1.35** |

**市值中性化后（PIT）：**

| 策略 | vs 随机 | IC | t 值 |
|---|---|---|---|
| quality | +3.65% | -0.0139 | -1.40 |
| quality_only | -46.37% | -0.0200 | -1.30 |
| margin | -0.21% | -0.0086 | -0.74 |

**样本内 vs 样本外（PIT）：**

| 策略 | 样本内 IC(t) | 样本外 IC(t) | 判断 |
|---|---|---|---|
| quality | **-0.0268（t=-2.59）** | +0.0049（t=+0.32） | 方向反转 |
| quality_only | -0.0262（t=-1.52） | -0.0060（t=-0.26） | 两段都负 |
| margin | -0.0164（t=-1.23） | -0.0004（t=-0.02） | 两段都负 |

**最刺眼的一条**：`quality` 在样本内 **t=-2.59（显著为负）**，样本外变成 +0.32。

**含义：高 ROE 的股票在 2020-2023 反而跌，到 2023-2026 完全失效。**

## 三个不可修复的缺陷

### ① 幸存者偏差

**问题**：股票池是 **2026 年当前**的成分股，用它回测历史，退市股不在池中。

**证据**：样本外「随机 20 只」都能 +134.39% —— 这批股票是活到今天的赢家。

**为什么修不了**：中证公告只给成分进出名单，**退市股没有免费数据源**。

### ② IC 统计上不可检验

**数学论证：**

```
周频 t ≈ IC × √N
要 t = 1.96：
  N=34  需要 IC = 0.336
  N=68  需要 IC = 0.238
  N=75  需要 IC = 0.226
  N=150 需要 IC = 0.160
  N=2500 需要 IC = 0.039

真实截面因子 IC 普遍 0.02 - 0.05
```

**即使信号真实存在，现有数据也永远无法证明。**

### ③ 前视偏差难以彻底消除

**财务数据只有报告期，没有公告日。** 只能用法定披露截止日近似：

```
一季报 (03-31) → 04-30 可得
半年报 (06-30) → 08-31 可得
三季报 (09-30) → 10-31 可得
年报   (12-31) → 次年 04-30 可得
```

## 踩过的坑（可复用的经验）

### 数据层

| 坑 | 现象 | 修法 |
|---|---|---|
| **东财全线不可用** | `stock_zh_a_hist` 0/8 失败 | 改用腾讯/新浪（都 100%） |
| **并发比串行更稳** | 串行成功率 55%，并发 100% | `ThreadPoolExecutor(workers=10)`，快 6 倍 |
| **千分位逗号** | 股本 `"19,405,918,198"` → NaN | 先 `.str.replace(",", "")` |
| **财务数据升序** | `iloc[0]` 是最老的 2023Q1 | 必须 `iloc[-1]` |
| **行业分类混用** | 证监会门类 + 申万行业并存 | 统一到申万一级 |
| **申万列表源挂** | `sw_index_first_info` 0/3 | 用硬编码 31 个行业代码 + 成分股接口 |
| **Qlib `.bin` 格式** | 第一个 float32 是起始索引 | 加 `np.hstack([[0], arr])` |
| **Windows multiprocessing** | Qlib 用 joblib，spawn 报错 | 必须放 `if __name__ == "__main__"` |

### 因子层

| 坑 | 现象 | 修法 |
|---|---|---|
| **Qlib `Ref` 语义** | `Ref($close,N)` 是 N 天前 | 动量必须 `$close/Ref(...)`，不是反过来 |
| **Qlib `Std` 用 ddof=1** | 参照实现偏离 2.6% | 必须 `np.std(..., ddof=1)` |
| **复权口径** | 六家模型都说 hfq 对 | **实测 qfq 才对**（跨除权日 20 日动量：qfq +17.70% / hfq +8.51%） |
| **配置未接线** | 改 config 系统纹丝不动 | 必须真的把参数传下去 |
| **上市时长误判** | 拉 3 年数据时「最早日期」=窗口起点 | 用 `list_date` 字段 |

### 回测层

| 坑 | 现象 | 修法 |
|---|---|---|
| **NaN 传播** | 全部结果 nan | 过滤 NaN + 剔除基准缺失的期 |
| **基准选错** | 全池等权自带小盘 alpha | 必须加「随机 N 只 bootstrap」对照 |
| **性能** | 57 万行面板反复布尔过滤 | 预索引 + bisect，快 10 倍 |
| **事后反向** | 看到 IC 为负才反转 | 这是样本内拟合，必须做样本外 |
| **PIT 查询慢** | 500 只 × 75 期 pandas 过滤 | 预建索引 + 二分查找 |

## 这套东西现在能干什么

### ✅ 能做的

**① 持仓风险体检**（唯一不需要预测力的功能）

检查 ST/退市风险、流动性、行业集中度、停牌、涨停买不进。
